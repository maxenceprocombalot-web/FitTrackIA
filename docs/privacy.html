Politique de confidentialité

FitTrack IA — Dernière mise à jour : 30 juillet 2026

1. Responsable du traitement

FitTrack IA est une application indépendante développée à titre personnel. Les données que vous saisissez sont stockées exclusivement sur votre appareil — aucun compte utilisateur, aucun serveur, aucune base de données distante.

2. Données collectées

L'application collecte et stocke localement sur votre appareil :

  • Profil : prénom, genre, âge, taille, poids, objectif
  • Séances d'entraînement : exercices, séries, répétitions, poids utilisé
  • Nutrition : repas, aliments, quantités, calories
  • Hydratation : volume d'eau consommé par jour
  • Poids corporel : historique de pesées
  • Messages avec le coach IA (historique du chat)
  • Photos de progression (stockées uniquement sur l'appareil)

Si vous activez la synchronisation Apple Santé, l'app écrit vos séances et votre poids dans Santé et lit votre dernier poids. Ces échanges restent sur votre appareil, gérés par Apple (HealthKit) ; FitTrack IA ne transmet jamais les données Santé à un serveur.

3. Finalité du traitement

Les données sont utilisées uniquement pour afficher vos statistiques personnelles (calories, macros, progression), calculer votre TDEE et vos objectifs nutritionnels, alimenter le coach IA en contexte personnalisé et générer vos bilans mensuels.

4. Partage des données avec des tiers

Deux services tiers reçoivent des données dans des conditions strictement encadrées :

OpenAI (coach IA) : lorsque vous envoyez un message au coach, les informations suivantes sont transmises à l'API OpenAI via une connexion HTTPS sécurisée : prénom, objectif, données physiques (âge, taille, poids), macros cibles, résumé des 7 dernières séances et repas. Ces données ne sont jamais stockées côté FitTrack IA ; leur traitement par OpenAI est soumis à la politique de confidentialité d'OpenAI.

OpenAI (estimation de repas) : si vous utilisez l'estimation par description ou par photo, le texte saisi ou la photo du plat (réduite, sans métadonnées de localisation) est transmis à OpenAI pour analyse, puis le résultat est renvoyé. FitTrack IA ne stocke jamais ces photos.

Open Food Facts : les termes de recherche saisis dans l'onglet Nutrition sont transmis à l'API publique Open Food Facts sous forme de requêtes anonymes (aucune donnée personnelle n'est transmise).

Aucune autre donnée n'est partagée avec des tiers. Il n'y a pas de publicité, pas d'analytique, pas de trackers.

5. Durée de conservation

Les données sont conservées sur votre appareil jusqu'à la désinstallation de l'application, ou l'utilisation de la fonction « Supprimer toutes mes données » dans les paramètres.

6. Vos droits (RGPD)

  • Accès : toutes vos données sont visibles directement dans l'application
  • Rectification : vous pouvez modifier votre profil à tout moment
  • Effacement : « Supprimer toutes mes données » dans Profil → Paramètres
  • Portabilité : Réglages → « Exporter mes données » (fichier chiffré)
  • Opposition : cessez simplement d'utiliser l'application

7. Sécurité

Vos données sont chiffrées sur l'appareil (AES-256) ; la clé de chiffrement est conservée dans le Keychain iOS et n'est jamais incluse dans les sauvegardes iCloud. Vous pouvez exporter une sauvegarde chiffrée par un mot de passe que vous seul connaissez. Toutes les communications avec des services tiers utilisent exclusivement le protocole HTTPS.

8. Modifications

Cette politique peut être mise à jour lors de nouvelles versions de l'application. La date de dernière mise à jour figure en haut de cette page.
